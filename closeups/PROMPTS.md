# Close-up prompts (24)

How to use them in ChatGPT:

1. Start a new chat for each customer.
2. Paste the **intro** prompt first. When you like the result, paste the **happy** and **angry** prompts in the same chat, so ChatGPT keeps the same face.
3. If the face drifts, add: "Keep exactly the same character as in the first image."
4. Download each image and save it in this folder with the file name shown.

Every prompt already includes the shared style, so each one can be pasted on its own.
